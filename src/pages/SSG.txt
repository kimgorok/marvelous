# getStaticPaths

동적 경로에 SSG를 적용하기 위해서는,
getStaticPaths 함수에서 return으로 반환하는 객체 안에는
pahts라는 값으로, 현재 이 페이지의 url 파라미터로 어떤 값(어떤 경로)이 존재할 수 있는지

### fallback(대체, 대비책, 보험)
pahts값에 해당하지 않는 url로 접속 요청을 보내면 나타날 대비책

1. fallback: false
- 없는 경로로 요청이 들어왔을 때 그냥 not found를 반환

2. fallback: blocking
- 없는 경로로 요청이 들어왔을 때 해당하는 페이지를 마치 SSR처럼 즉시 생성함
단, 페이지 크기에 따라서 SSR 시간동안 로딩이 발생할 수 있음

3. fallback: true
- 없는 경로로 요청이 들어왔을 때 일단 즉시 Props(페이지에 필요한 데이터) 없는 페이지(레이아웃 정도만)를 반환함
그 후 Props를 계산하고 추후에 Props만 따로 반환함

### isFallback
useRouter의 isFallback을 활용해서 fallback 상태일 때의 표시를 설정할 수 있음

```js
if (router.isFallback) return "fallback 로딩중입니다.";
```

이렇게 로딩으로 한 번에 처리하지 않고 isFallback처리를 따로 하는 이유는
fallback이 완료되고나서도 진짜 오류가 발생해서 데이터를 불러오지 못할 경우에는 따로 표시를 하기 위해서임
