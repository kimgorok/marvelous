# 스트리밍

오래 걸리는 컴포넌트의 렌더링을 사용자가 좀 더 좋은 환경에서 기다릴 수 있도록 빨리 렌더링
할 수 있는 컴포넌트들을 보내주는 것

다이나믹 페이지는 풀 라우트 캐시에 저장이 안되고 api 요청이 오래걸려 스트리밍을 적용함

page.tsx와 같은 위치에 loading.tsx 파일을 만들어 주면, 그 페이지는 스트리밍이 적용됨
layout.tsx와 같이 해당 경로 하위에 다 로딩.tsx가 적용됨.
스트리밍은 async를 사용하고 있는 page 비동기 컴포넌트에만 적용됨

브라우저의 쿼리스트링만 변경될 때에는 스트리밍이 적용되지 않음

쿼리스트링이 변경될 때 로딩상태를 보여주기 위해서는 Suspense의 key를 사용할 수 있음

```js
    <Suspense key={searchParams.q || ""} fallback={<div>로딩...</div>}>
      <SearchResult q={searchParams.q || ""} />
    </Suspense>
```
다음과 같이 Suspense로 컴포넌트로 감싸고 key값을 지정해주면, 해당 key 값이 변화할 때마다
fallback에 작성한 로딩 상태를 표시할 수 있음

> react-loading-skeleton이라는 스켈레톤을 자동으로 만들어주는 라이브러리도있음
